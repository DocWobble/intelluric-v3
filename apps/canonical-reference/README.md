# Parametric style prototype

This executable page demonstrates the InTelluric visual foundation with
semantic HTML, direct artwork, and replaceable fixture content.

Its structural frame, recessed wells, mineral surfaces, mineral buttons, tones,
and stitched noise field come exclusively from `ui/visual-system.css`. Its
words, labels, records, and `data-action-id` values are not product contracts.
The page has no production destinations or framework component API.
