# intelluric-v3

Canonical repository for the InTelluric public site and Pitch Synthase.

Frontend implementation begins at [`contracts/VISUAL_AUTHORITY.md`](contracts/VISUAL_AUTHORITY.md). The binding screenshot fixtures live under [`reference/visual-contract/`](reference/visual-contract/). Shared values come from `@intelluric/design-tokens`; all repeated browser material construction comes from `@intelluric/material-system`.

Run:

```bash
npm run check
```

A passing check proves that token outputs are current, the screenshot fixtures are intact, all required material primitives exist, and no competing visual grammar has appeared outside the canonical packages.
