# intelluric-v3

The singular visual foundation for InTelluric.

- [`canon/homepage-canon.jpg`](canon/homepage-canon.jpg) is the sole page-level visual authority.
- [`ui/visual-system.css`](ui/visual-system.css) is the sole visual implementation surface.
- [`apps/canonical-reference/`](apps/canonical-reference/) is one executable semantic demonstration with replaceable fixture content.

The foundation intentionally does not define a site map, routes, production links, page names, backend behavior, or product workflow. Those inputs can change without changing the design.

```bash
npm run build
npm run check
npm run serve
```
